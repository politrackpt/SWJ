Description

  • This is the Core module from the Portuguese Political Structures (POLIS) Ontology. This ontology enables the modelling of the core institutional structure of the Portuguese Parliament.

  • Este é o módulo Core da ontologia Portuguese Political Structures (POLIS). Esta ontologia permite modelar a estrutura institucional central do Parlamento português.
